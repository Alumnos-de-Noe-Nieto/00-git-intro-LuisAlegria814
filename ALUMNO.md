## ¿Qué es Git?

Git es un sistema de control de versiones que permite a los programadores
guardar cambios en el código y mantener un historial de dichos cambios para
asi poder acceder a ellos y poder colaborar con otros sin perder cambios.

## Por qué necesitamos Git

Sin Git, cuando trabajamos en equipo es muy probable que ocurran problemas
en el desarrollo de un proyecto por temas de cambios perdidos por sobreescribir
el código de otro o trabajar en un archivo anticuado, aumentando asi el riesgo de
retrabajo

## Los 3 conceptos clave de Git

1. **Repositorio:** Es la carpeta del proyecto que contiene la carpeta .git, donde Git almacena todo el historial de cambios realizados con commits.
2. **Commit:** Es la accion con la que git guarda de forma permanente los cambios realizados, creando un punto en el historial del proyecto.
3. **Rama:** Es una rama alterna por así decirlo dentro del repositorio que permite cambiar cosas sin afectar la rama principal del proyecto.

## Los comandos que aprendí
- git init - Inicializa Git en una carpeta
- git add - Prepara los cambios para guardar
- git commit - Guarda los cambios con un mensaje
- git push - Sube tus cambios a GitHub
- git pull - Descargas cambios de tus compañeros desde GitHub
- git config --global user.name - configura el nombre del usuario
- git config --global user.email - configura el correo del usuario

## Mi reflexión final

Lo más importante que aprendí de Git es...
que mientras mas grande sea el proyecto y mas personas involucre, es mas imposible trabajar
sin git. Git se encarga de solucionar problemas de versiones y cambios mientras que también 
documenta quien realiza cada cambio y cuando se realizo, ayudando asi a al correcto desarrollo
del proyecto.
